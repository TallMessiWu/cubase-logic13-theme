# 已有工程：全局主题与工程色板是两回事

CLI 只改两个全局配置文件，不读写 `.cpr`。旧工程和模板可以保存自己的颜色集，因此全局设置成功不等于旧工程立刻换色。

## 将新 48 色板载入一个旧工程

1. 先备份工程文件，或在 Cubase 内另存副本。
2. 确认全局主题已应用并重启 Cubase。
3. 打开目标工程。
4. 进入 **工程 / Project → 工程颜色设置 / Project Colors Setup → 选项 / Options**。
5. 选择 **重置颜色集至默认 / Reset Color Set to Default**，然后应用。
6. **不要选择 Reset Color Set to Factory Settings**；那会恢复原厂颜色。
7. 检查工程的色板是否出现 `01 Logic Blue`、`02 Orchid` 等名称，共 48 色。

加载色板会按旧颜色编号重新映射已有轨道/事件，未必是自上而下 1、2、3 的顺序。

## 如果要求现有轨道顺序上色

逐条选择轨道，用 **应用颜色至选定轨道 / Apply Colors to Selected Tracks** 选择对应色号，再保存工程。Cubase 14 的原厂快捷键通常为 `Alt+Shift+C`，但用户可能修改过快捷键，应先核实菜单。

- 第 1 条 → `01 Logic Blue`
- 第 2 条 → `02 Orchid`
- 第 3 条 → `03 Lagoon`
- 第 4 条 → `04 Magenta`
- 第 5 条 → `05 Sky Cyan`
- 第 6 条 → `06 Amber`
- 依此类推，超过 48 条时再决定是否循环。

“使用上一轨颜色 +1”只控制新建轨道，**不是按轨道编号自动重染已有轨道**。不要为了展示颜色而启用禁用轨道；禁用时颜色被压暗是正常行为。事件若设置了独立颜色，也不一定跟随轨道色。

## 回退范围

CLI 的 `restore` 只回退应用配色，不会恢复工程内部的色板或轨道颜色。工程回退需要使用该工程自己的备份。
